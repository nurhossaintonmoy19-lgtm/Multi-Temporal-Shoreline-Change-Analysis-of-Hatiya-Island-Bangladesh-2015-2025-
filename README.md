# Multi-Temporal Shoreline Change Analysis of Hatiya Island, Bangladesh (2015–2025)

## Project Overview

Hatiya Island, located within the Meghna estuary of Bangladesh, is a dynamic coastal environment characterized by continuous shoreline changes associated with erosion, accretion, sediment deposition, and coastal processes.

This project aims to analyze the spatial and temporal changes in the shoreline of Hatiya Island between 2015 and 2025 using Landsat satellite imagery, Geographic Information Systems (GIS), and Remote Sensing techniques.

Multi-temporal satellite images will be processed to extract shorelines for selected years. The extracted shorelines will subsequently be compared to identify areas of erosion and accretion and to quantify shoreline displacement and change rates.

The project will utilize geospatial techniques and shoreline change metrics to visualize and interpret the changing coastal morphology of Hatiya Island.

## Objectives

- To delineate shorelines of Hatiya Island for 2015, 2020, and 2025.
- To analyze spatial and temporal patterns of shoreline changes.
- To identify erosion and accretion zones.
- To quantify shoreline displacement and change rates using shoreline change metrics.
- To visualize shoreline dynamics through GIS-based maps.

2. Satellite Image Acquisition
